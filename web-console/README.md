# PixelMC Manager Web Console

[中文](#中文) · [English](#english)

## 中文

PixelMC Manager 的网页界面，把服务器状态和常用管理操作放到同一个工作空间。

### 功能

- 总览、性能曲线、玩家档案、维度列表和服务器管理。
- 支持深浅主题、搜索、分页和实时数据更新。
- 在侧栏中整合 MemorialTitles 等扩展。

### 使用

界面由 [Manager Service](../manager-service/README.md) 提供，部署时无需单独运行前端开发服务器。

## English

The web interface for PixelMC Manager, bringing server monitoring and routine administration into one workspace.

### Features

- Overview, performance charts, player profiles, dimensions, and server administration.
- Use dark or light themes, search, pagination, and live updates.
- Access extensions such as MemorialTitles from the sidebar.

### Usage

The interface is served by [Manager Service](../manager-service/README.md); a separate frontend development server is not needed for deployment.
